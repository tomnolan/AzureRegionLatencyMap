Azure Region Latency Map

Visualizes network latency between Azure regions on an interactive map. Latency data is sourced from the Azure network latency statistics published by Microsoft. Region location data is retrieved directly from Azure via PowerShell or the Azure CLI.

Latency Data

Round-trip latency figures are sourced from the Azure network latency page on Microsoft Learn. The dataset is updated periodically by Microsoft.

Region Data

Region metadata (coordinates, geography group, availability zones) is retrieved from the Azure CLI via az account list-locations.

Restricted Access

Restricted Access status is not exposed by az account list-locations. It is sourced separately from the Azure regions list page on Microsoft Learn, which documents which regions require special access approval.

Connection Data
Select source and destination regions using the filters, then open the table to view latency data.
